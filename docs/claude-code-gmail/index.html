Open in AI Agent for Gmail
All browsers · GitHub (MIT)

Resolve the work behind Gmail threads in Claude Code before drafting a reply.

An email rarely lives in isolation: answering properly means checking local repositories, invoices, spreadsheets or Sent mail first. Open in AI Agent launches Claude Code in your chosen working folder with the thread ID, mailbox and Gmail link, and asks it to do the substantive investigation before drafting.

Add to Chrome (Free) Edge, Brave, Arc & Firefox

Version 1.6.0 · Works with Claude Desktop & claude CLI (-n session naming).

Workflow highlights

  • Automatic session naming: Single threads and multi-thread separate picks open sessions named straight from the cleaned email subject (or via claude -n with the optional companion helper).
  • Explicit approval guardrails: Every prompt instructs Claude Code to treat email bodies and attachments strictly as untrusted data, never follow links or commands inside mail, and show exact proposed actions and risks before changing anything outside your working folder.
  • Unread inbox triage: Sort up to 25 unread threads from Gmail's toolbar and optionally save approved replies back to Gmail Drafts without sending.

Read the full prompt specification and install instructions on openinaiagent.com.
