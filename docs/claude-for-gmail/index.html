Open in AI Agent for Gmail
All browsers · GitHub (MIT)

Use Claude and Claude Code inside Gmail without giving a third party your mailbox.

Most "Claude for Gmail" extensions route your emails through an external backend and charge a second monthly subscription on top of Claude Pro or Max. Open in AI Agent runs strictly inside your browser and hands threads straight to your own claude.ai account or the Claude Code desktop agent.

Add to Chrome (Free) Edge, Brave, Arc & Firefox

Version 1.6.8 · MIT open source · Zero servers, zero analytics, zero OAuth middleman.

What it does with Claude and Claude Code

  • One right-click from Gmail: Pick Ask Claude to open claude.ai/new with every message in the thread formatted cleanly (with optional composer auto-fill), or pick Open in Claude Code to launch a desktop session named after the email's subject.
  • Separate sessions when you tick multiple emails: Tick 2 to 5 threads in your inbox to open separate auto-filled Claude tabs or named Claude Code sessions via the optional local helper (or switch to a 25-thread task-sorted batch).
  • Unread inbox triage without marking mail read: Click Triage unread in Gmail's toolbar to read up to 25 unread threads from Gmail's print view in the background and sort them into Action, Consolidate, Disregard and Draft.
  • Prompt-injection stripping built in: Invisible Unicode tag/bidi characters are removed and lookalike delimiter markers inside untrusted emails are broken up before the prompt is built.

Custom prompts for your own workflow

Choose between three built-in prompt styles (Resolve fully, Quick summary and reply, or Draft replies only), or save up to three custom playbooks in Settings that sync privately via your browser.

See the interactive walkthrough and full prompt inspector on the home page.
