to your AI agent.

How it works

1

Right-click

Two items appear at the top of Gmail's menu, and in Chrome's menu inside an open thread.

2

Session opens

Claude Code pre-fills a new session for you to start. Codex starts straight away.

3

Agent reads the thread

It fetches the conversation through its own Gmail connection, sums up where things stand and drafts a reply.

Safe by default

Nothing leaves your machine

No server, no analytics, no tracking. It reads only the mailbox address and thread ID.

Drafts, not sends

The prompt tells the agent to draft replies and send nothing without your approval.

No injected instructions

The sender-written subject never goes into the prompt, so a sender can't slip in commands.

What the agent receives

Install in two minutes

  1. Download the zip and unzip it somewhere it will stay.
  2. Open chrome://extensions, switch on Developer mode, click Load unpacked and pick the folder.
  3. Paste the folder you want sessions to open in, then Save.
  4. Reload Gmail and right-click a thread. The first time, tick Always allow.

You need the Claude desktop app and/or OpenAI's ChatGPT desktop app with Codex, with Gmail connected for the same mailbox. Tested on macOS.
