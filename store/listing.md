## Store listing tab

**Name** (from manifest): Open in AI Agent for Gmail: Claude, ChatGPT & Codex

**Summary** (from manifest, 123 of 132 characters): Right-click Gmail threads to open separate sessions in Claude, ChatGPT, Gemini, Claude Code, Codex or Antigravity. Private.

**Description:**

Right-click one email or tick several in Gmail to open separate named sessions in Claude, ChatGPT, Gemini, Claude Code, Codex or Antigravity, plus six more web AIs shown in the screenshots. Triage up to 25 unread threads at once without marking them read. Runs locally on your computer: open source (MIT), no server, no account and no subscription.

Set up in two steps
1. Add the extension.
2. Tick the AIs you use on the settings page that opens.
Then right-click any email. Tabs that are already open need no reload.

New in 1.6.0: separate sessions, desktop companion and auto-fill
• Separate sessions per ticked email: ticking 2 to 5 emails opens a separate chat tab or named desktop session for each thread by default, so unrelated threads never mix and each conversation gets titled after its own subject. Prefer one combined prompt? Switch Multiple emails to One combined batch on Settings or in the toolbar popup (6 to 25 ticked emails combine automatically).
• Four desktop agents: Claude Code, Codex, Antigravity and Gemini CLI launch in your working folder and read threads through their own mailbox connection. Run the optional local companion script once to open CLI and IDE sessions directly with named titles.
• Optional prompt-box auto-fill: enable composer auto-fill on Settings to place the prepared prompt straight into the input box on newly opened Claude, ChatGPT and Gemini tabs without pressing Enter, so nothing sends until you check it.

What happens when you click
• Inbox list: your picks appear at the top of the inbox's own right-click menu.
• Inside an open thread: right-click and use the browser's menu.
• Web AIs: copies the subject, senders, dates and message text with a structured resolve-first prompt, then opens the site in a new tab next to your inbox (1.2 s, or 250 ms with optional auto-fill). Paste (or let optional auto-fill place it), review and press Enter.
• Copy thread for any AI: copies the prepared prompt and thread to your clipboard and opens nothing.
• Inbox toolbar button: sits just before More. Reads Send to AI in an open thread, Send 3 to AI with three ticked, and Triage unread with nothing ticked.
• Browser toolbar icon and keyboard shortcuts: open the quick-pick list (with a per-send prompt style selector) or send straight to the AI you used last, never to an agent that starts before you review.

Several emails and Triage unread
• Tick up to 25 emails, or click Triage unread in the inbox toolbar with nothing ticked.
• Background print-view reader: reads ticked and triaged threads in the background without clicking or opening them, so unread messages stay unread.
• Triage unread sorts every thread into Action (owner, deadline and next step), Consolidate (related threads merged), Disregard (newsletters, alerts and receipts) and Draft (substantive replies, saved as drafts only when you approve).

Prompt styles, saved prompts and selected text on any page
• Choose Resolve fully (default), Quick summary and reply, or Draft replies only, or save up to three custom prompts of your own (up to 4,000 characters per group, synced with your browser profile).
• Select text on any other webmail or web page, right-click it and pick an AI: uses activeTab on that one tab only, strips hidden characters and reads nothing else on the page.

Privacy and safety
• Runs entirely on your computer: zero external servers, zero analytics and zero tracking.
• Every prompt frames email text inside lookalike-safe markers as untrusted data, not instructions, and ends with an explicit approval gate forbidding sending, paying, deleting or changing anything without your confirmation.
• Built-in inbox self-check and a Report a problem link that never includes email text or addresses.

Compatibility
• Chrome 116+ and Chromium browsers that install from the Chrome Web Store (website lists the Edge and Firefox builds). Works with Gmail in a desktop browser, not the mobile app.
• Free and open source under the MIT licence. If it saves you time, the settings page includes an optional donate link straight to Friends of Larnaca Cats, a volunteer street-cat charity in Cyprus.

Not affiliated with or endorsed by Google, Anthropic, OpenAI or any other AI provider. All trademarks belong to their respective owners.

## Privacy tab

**Single purpose:** Hands email to the AI you pick: the Gmail threads you right-click, tick, have open or ask it to triage, their links, or text you select on a page, such as an email in another webmail.

**Permission justifications**
- `contextMenus`: adds the AIs the user picked (for example "Ask ChatGPT about this thread", "Open thread in Claude Code", "Copy thread for any AI") to Chrome's right-click menu inside an open Gmail thread: one item when one AI is picked, grouped under the extension's name when there are more. From 1.4.0 it also adds, on any page, items such as "Ask ChatGPT about the selected text" that show only while text is selected. They use the `selectionText` Chrome passes with the click and the `activeTab` grant that comes with it (below), so the extension needs no host access to those sites.
- `storage`: saves the user's settings (which AIs appear in the menus, Gmail's toolbar button and the toolbar list, whether that button shows, the working folder for desktop sessions, from 1.4.0 the user's own instructions for the prompts, if any, which from 1.5.0 are the user's saved prompts, up to three, each its own item, and the default prompt style) and, in local storage, which AI the user picked last, for the "send to the AI you used last" keyboard shortcut.
- `offscreen`: copies the prepared prompt to the clipboard when the user picks a web AI or "Copy" from either right-click menu. The background service worker has no page to copy from, so it uses one offscreen document created with reason CLIPBOARD, which only writes the prompt to the clipboard.
- `clipboardWrite`: puts the prepared prompt on the clipboard so the user can paste it into the AI they chose.
- `scripting`: used on mail.google.com, and from 1.4.0 in the one tab where the user picked a selected-text item (through `activeTab`). On install and update, it injects the extension's own packaged scripts (`targets.js`, `toast.js` and `content.js`, the same files as the content script) into Gmail tabs that are already open, so the user does not have to reload Gmail. After a selected-text pick, it runs packaged code in that tab: one function that returns the selected text, the extension's own `toast.js` and one function that shows its confirmation note. When the user ticks several emails and picks a web AI or "Copy", it runs one packaged function in the Gmail page that returns Gmail's session key (`window.GLOBALS[9]`), which the content script needs to request each ticked thread's print view from mail.google.com. No remote code. The key is not stored or sent anywhere except in those requests to mail.google.com.
- `activeTab`: when the user picks a selected-text item on a page, or uses the toolbar list or the second keyboard shortcut on a page that is not Gmail, reads the text the user selected in that tab (keeping its line breaks) and shows the extension's confirmation note in that page; in Firefox it also opens the desktop app's link from the page. Nothing else on the page is read, and the access ends when the user leaves the page. It shows no install warning.
- Host access `https://mail.google.com/*` (content script and host permission): adds the chosen AIs to Gmail's own right-click menu; after the user picks one, reads the mailbox address and thread IDs (desktop agents; Claude Code, Antigravity and Gemini CLI also the subjects) or the chosen threads' text (web AIs and copy) to build the prompt; for several ticked emails, requests each one's print view from mail.google.com in the same tab; shows a short confirmation inside Gmail; adds one button to Gmail's toolbar that offers the same AIs for the open thread, the ticked emails or, with nothing ticked, the unread emails on that page of the list, which it reads from the list and their print view without opening them; answers the settings page's Gmail self-check with counts and yes-or-no results, never email text. The toolbar list and the keyboard shortcuts act through the same content script. It is listed as a host permission from 1.2.0 because `scripting` needs it. The content script already matched the same host.
- Optional `nativeMessaging` (from 1.6.0, off at install): requested only when the user clicks "Enable companion helper" on the settings page. Passes the prepared desktop prompt to the local open-source `com.openinaiagent.host` Node script on the user's computer so Google Antigravity (`agy`), Gemini CLI (`gemini`), Claude Code (`claude -n`) and Codex can open directly in the user's working folder with named sessions.
- Optional host access `https://claude.ai/*`, `https://chatgpt.com/*`, `https://gemini.google.com/*` (from 1.6.0, off at install): requested only when the user ticks "Auto-fill prompt box in Claude, ChatGPT and Gemini" on the settings page. Fills the prepared prompt into the composer box on the newly opened tab without pressing Enter, so nothing is sent until the user reviews it.

**Remote code:** No. All JavaScript ships in the package.

**Data usage (tick):**
- Personally identifiable information: yes (the signed-in Gmail address, and the names and email addresses of senders, and for several emails also recipients, in the chosen threads).
- Personal communications: yes (the subject, dates and message text of the threads the user chooses for a web AI or copy, including the unread threads the user asks it to triage; for desktop agents the thread IDs, and for Claude Code the subjects; and any text the user selects on a page and sends to an AI, which may be an email in another webmail).
- Website content: yes (the text read from the Gmail page and from Gmail's print view, and text the user selects on any page, to build the prompt).
- All other categories (health, financial and payment, authentication, location, web history, user activity): no. Gmail's session key, read for the print-view requests, is not a password or sign-in cookie; it is used only in requests to mail.google.com from the user's own Gmail tab and is never stored or sent elsewhere.

All of it is used only to build the prompt the user asked for. It goes onto the user's own clipboard or to a desktop app on the user's computer, never to the developer's or anyone else's server. The user's own instructions for the prompts, new in 1.4.0 and saved prompts from 1.5.0, are text the user writes on the settings page: they are kept in `chrome.storage.sync` with the other settings (so Chrome Sync stores them if the user syncs extension data) and go only into the prompts the user starts. A saved prompt's name is a label and goes nowhere. The extension's only own network requests are the print-view requests to mail.google.com for emails the user ticked. The settings page's Report a problem link opens GitHub's new-issue form with the version, the browser and operating system, and the self-check results filled in. They travel in the form's web address, so GitHub receives them when the page opens; nothing is posted unless the user submits the form, and it never holds email text.

**Certify all three:** not sold or transferred to third parties outside the approved use; not used for purposes unrelated to the single purpose; not used to determine creditworthiness or for lending.

**Privacy policy URL:** https://github.com/thomasoclegg/gmail-to-agent/blob/main/PRIVACY.md

**Test instructions** (optional field): No account or login for the extension. Install it; on the settings page that opens, Claude and ChatGPT are already picked. Open Gmail, right-click an email in the inbox and choose "Ask ChatGPT". A ChatGPT tab opens next to Gmail and the thread is on the clipboard, ready to paste. For several emails, tick two or more in the inbox, right-click one of them and choose "Ask ChatGPT about 2 emails" (the number follows how many are ticked). With a thread open, the "Send to AI" button in Gmail's toolbar and the extension's toolbar icon list the same AIs and do the same. In the inbox with nothing ticked, the same button reads "Triage unread" and hands over the unread emails on that page of the list without opening them. On any other page, select some text, right-click it and choose "Ask ChatGPT about the selected text". On the settings page, under "Prompts", the default style is Resolve fully, the built-in prompts; choose "Quick summary and reply" or "Draft replies only" to test the lighter ones, or press "Add a saved prompt" and type text that replaces the built-in task for emails. In the toolbar list, the "Style for this send" picker above the AIs changes the style for that one pick. Resolve fully also asks the AI to set aside each task that cannot be finished now (one that waits on someone else or a later date, or is a large piece of work of its own) with a short brief: Claude Code by proposing a session for the user to start, never starting one itself; Codex, which starts before the user has read its prompt, by giving the brief in its answer for the user to start after replying; a web AI or Copy, for several emails, with a short Handover to paste into a new chat.
