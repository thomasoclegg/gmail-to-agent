# Step lists for the videos

Generated by `node media/record.mjs --steps` from the storyboards in `media/storyboards/`. Put each list next to its video: the videos are silent, and this is their text alternative.

## Hero loop

`docs/media/hero.webm`, `docs/media/hero.mp4`, `docs/media/hero.gif`, 13 s

1. In Gmail, right-click an email.
2. Pick an AI from the top of the menu, for example Ask ChatGPT.
3. The extension opens the email and copies the whole thread. The note at the bottom left says so.
4. A moment later the AI opens in a new tab. Press Ctrl+V to paste the thread.
5. Check what you pasted, then press Enter. Nothing is sent until you do.

## Clip 1: pick your AIs

`docs/media/clip-pick-ais.webm`, `docs/media/clip-pick-ais.mp4`, 10 s

1. Click the extension's icon in Chrome's toolbar. If you can't see it, pin it from the puzzle-piece menu.
2. The settings page opens. Tick the AIs you use. Each tick saves straight away.
3. Back in Gmail, right-click an email. The AIs you ticked are at the top of the menu, in the same order.

## Clip 2: Claude Code and Codex

`docs/media/clip-desktop-agent.webm`, `docs/media/clip-desktop-agent.mp4`, 13 s

1. In the settings page, tick Claude Code or Codex and add a working folder. The app needs Gmail connected for the same mailbox.
2. In Gmail, right-click an email and pick Open in Claude Code (or Open in Codex).
3. The first time, Chrome asks whether to open the app. Tick Always allow, then click Open.
4. The app opens with a short prompt: the mailbox, the thread ID and the Gmail link, plus the subject for Claude Code so the session is named after the email. The message text is never in it.
5. The app reads the thread through its own Gmail connection. Claude Code waits for you to press Enter; Codex starts by itself once a working folder is set.

## Clip 3: copy for any AI

`docs/media/clip-copy.webm`, `docs/media/clip-copy.mp4`, 7 s

1. In the settings page, tick Copy thread for any AI.
2. In Gmail, right-click an email and pick Copy thread for any AI.
3. The extension opens the email and copies the whole thread. Nothing else opens.
4. Paste it into any AI chat with Ctrl+V (Cmd+V on a Mac), check it, then send it.

## Clip 4: several emails at once

`docs/media/clip-bulk.webm`, `docs/media/clip-bulk.mp4`, 12 s

1. In the Gmail inbox, tick two or more emails (up to 25).
2. Right-click one of the ticked emails and pick an AI, for example Ask Claude about 3 emails.
3. The extension reads each thread in the background without opening it, so unread emails stay unread.
4. The AI opens in a new tab. Press Ctrl+V (Cmd+V on a Mac) to paste, check it, then press Enter.
5. The prompt asks the AI to group the emails into tasks, put the most urgent first and draft replies. Claude Code and Codex get the thread IDs and links instead of the message text, and Claude Code also gets each subject.

## Walkthrough (YouTube)

`store/video/walkthrough-1920x1080.mp4`, `store/video/walkthrough-1920x1080.srt`, 63 s

1. Install the extension. The settings page opens; you can open it again from the extension's icon in Chrome's toolbar.
2. Tick the AIs you use. Each tick saves straight away.
3. In Gmail, right-click an email and pick an AI, for example Ask Gemini. The extension opens the email and copies the whole thread.
4. The AI opens in a new tab next to Gmail. Press Ctrl+V (Cmd+V on a Mac) to paste the thread and read it through. Nothing is sent until you press Enter.
5. To work on several emails at once, tick them, right-click one of them and pick an AI. Each thread is read without opening it, and the AI is asked to sort them into tasks.
6. Copy thread for any AI copies the thread but opens no AI, so you can paste it wherever you like.
7. Claude Code and Codex open on your desktop with a short prompt: the mailbox, the thread ID and the Gmail link, plus the subject for Claude Code. The message text is never in it. They read the thread through their own Gmail connection.
8. It runs on your computer: no server, no account, no tracking.
